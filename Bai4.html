Bài 4: Phương trình lượng giác cơ bản

Kiến thức trọng tâm

  • Phương trình tương đương

    • \(f(x) = 0 \Leftrightarrow g(x) = 0\)

    Từ lúc này giải phương trình sẽ dùng dấu tương đương, kí hiệu \(\ \Leftrightarrow\)

    sinx = m (\(\ -1 \le m \le 1\))

    sinx = m \(\Leftrightarrow\) sinx = sinα

    \(\Leftrightarrow\) \(\left[ \begin{array}{1} x = α + k2π \\ x = π - α + k2π \end{array} \right.\) ( k \(\in\) Z)

    Ví dụ 1

    Giải phương trình \(\sin x = \frac{1}{2}\).

    Xem lời giải

    \(\sin x = \frac{1}{2} \Leftrightarrow \sin x = \sin\frac{\pi}{6}\)

    \(\Leftrightarrow \left[ \begin{array}{l} x = \frac{\pi}{6} + k2\pi \\ x = \pi - \frac{\pi}{6} + k2\pi \end{array} \right. \Leftrightarrow \left[ \begin{array}{l} x = \frac{\pi}{6} + k2\pi \\ x = \frac{5\pi}{6} + k2\pi \end{array} \right.\ (k \in \mathbb{Z})\)

    Ví dụ 2

    Giải phương trình \(\sin x = 2\).

    Xem lời giải

    Vì \(-1 \le \sin x \le 1\) với mọi \(x\) mà \(2 \gt 1\), nên phương trình vô nghiệm.

    cosx = m (\(\ -1 \le m \le 1\))

    cosx = m \(\Leftrightarrow\) cosx = cosα

    \(\Leftrightarrow\) \(\left[ \begin{array}{1} x = α + k2π \\ x = - α + k2π \end{array} \right.\) ( k \(\in\) Z)

    Ví dụ 1

    Giải phương trình \(\cos x = -\frac{1}{2}\).

    Xem lời giải

    \(\cos x = -\frac{1}{2} \Leftrightarrow \cos x = \cos\frac{2\pi}{3}\)

    \(\Leftrightarrow x = \pm\frac{2\pi}{3} + k2\pi\ (k \in \mathbb{Z})\).

    Ví dụ 2

    Giải phương trình \(\cos 2x = \frac{1}{2}\).

    Xem lời giải

    \(\cos 2x = \cos\frac{\pi}{3} \Leftrightarrow 2x = \pm\frac{\pi}{3} + k2\pi\)

    \(\Leftrightarrow x = \pm\frac{\pi}{6} + k\pi\ (k \in \mathbb{Z})\).

    tanx = m

    tanx = m \(\Leftrightarrow\) tanx = tanα \(\Leftrightarrow\) x = α + kπ ( k \(\in\) Z)

    Ví dụ 1

    Giải phương trình \(\tan x = \sqrt{3}\).

    Xem lời giải

    \(\tan x = \tan\frac{\pi}{3} \Leftrightarrow x = \frac{\pi}{3} + k\pi\ (k \in \mathbb{Z})\).

    Ví dụ 2

    Giải phương trình \(\tan\left(2x - \frac{\pi}{4}\right) = 1\).

    Xem lời giải

    \(\tan\left(2x - \frac{\pi}{4}\right) = \tan\frac{\pi}{4} \Leftrightarrow 2x - \frac{\pi}{4} = \frac{\pi}{4} + k\pi\)

    \(\Leftrightarrow 2x = \frac{\pi}{2} + k\pi \Leftrightarrow x = \frac{\pi}{4} + \frac{k\pi}{2}\ (k \in \mathbb{Z})\).

    cotx = m

    cotx = m \(\Leftrightarrow\) cotx = cotα \(\Leftrightarrow\) x = α + kπ ( k \(\in\) Z)

    Ví dụ 1

    Giải phương trình \(\cot x = -1\).

    Xem lời giải

    \(\cot x = \cot\left(-\frac{\pi}{4}\right) \Leftrightarrow x = -\frac{\pi}{4} + k\pi\ (k \in \mathbb{Z})\).

    Ví dụ 2

    Giải phương trình \(\cot\left(x + \frac{\pi}{6}\right) = \sqrt{3}\).

    Xem lời giải

    \(\cot\left(x + \frac{\pi}{6}\right) = \cot\frac{\pi}{6} \Leftrightarrow x + \frac{\pi}{6} = \frac{\pi}{6} + k\pi\)

    \(\Leftrightarrow x = k\pi\ (k \in \mathbb{Z})\).

  • LƯU Ý

    • sinα = 0 \(\Leftrightarrow\) α = kπ

    sinα = 1 \(\Leftrightarrow\) α = \(\frac{π}{2}\) + k2π

    sinα = -1 \(\Leftrightarrow\) α = \(\frac{-π}{2}\) + k2π

    cosα = 0 \(\Leftrightarrow\) α = \(\frac{π}{2}\) + kπ

    cosα = 1 \(\Leftrightarrow\) α = k2π

    cosα = -1 \(\Leftrightarrow\) α = π + k2π
