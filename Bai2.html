Bài 2: Công thức lượng giác

Kiến thức trọng tâm:

  • Công thức cộng

    • "sin thì sin cos cos sin"

    sin( a + b ) = sina.cosb + cosa.sinb

    sin ( a - b ) = sina.cosb - cosa.sinb

    "cos thì cos cos sin sin dấu trừ"

    cos ( a + b ) = cosa.cosb - sina.sinb

    cos( a - b ) = cosa.cosb + sina.sinb

    "tan thì ta tổng hai tan, chia cho 1 trừ tan ta tan mình"

    tan ( a + b ) = \(\frac{tana + tanb}{ 1 - tana.tanb}\)

    tan ( a - b ) = \(\frac{tana - tanb}{1 + tana.tanb}\)

    Ví dụ 1

    Tính \(\sin 75^\circ\).

    Xem lời giải

    \(\sin 75^\circ = \sin(45^\circ + 30^\circ) = \sin 45^\circ \cos 30^\circ + \cos 45^\circ \sin 30^\circ\)

    \(= \frac{\sqrt{2}}{2} \cdot \frac{\sqrt{3}}{2} + \frac{\sqrt{2}}{2} \cdot \frac{1}{2} = \frac{\sqrt{6} + \sqrt{2}}{4}\).

    Ví dụ

    Cho \(\sin a = \frac{3}{5}\), \(\cos b = \frac{12}{13}\) với \(0 \lt a \lt \frac{\pi}{2}\) và \(0 \lt b \lt \frac{\pi}{2}\). Tính \(\sin(a + b)\).

    Xem lời giải

    Vì \(a, b\) thuộc góc phần tư thứ nhất nên \(\cos a = \sqrt{1 - \frac{9}{25}} = \frac{4}{5}\) và \(\sin b = \sqrt{1 - \frac{144}{169}} = \frac{5}{13}\).

    \(\sin(a + b) = \sin a \cos b + \cos a \sin b = \frac{3}{5} \cdot \frac{12}{13} + \frac{4}{5} \cdot \frac{5}{13} = \frac{56}{65}\).

    Ví dụ 3

    Tính \(\tan 75^\circ\).

    Xem lời giải

    \(\tan 75^\circ = \tan(45^\circ + 30^\circ) = \frac{\tan 45^\circ + \tan 30^\circ}{1 - \tan 45^\circ \cdot \tan 30^\circ} = \frac{1 + \frac{1}{\sqrt{3}}}{1 - \frac{1}{\sqrt{3}}}\)

    \(= \frac{\sqrt{3} + 1}{\sqrt{3} - 1} = \frac{(\sqrt{3} + 1)^2}{2} = 2 + \sqrt{3}\).

  • Công thức nhân đôi

    • sin2a = 2sina.cosa

    cos2a = cos²a - sin²a = 1 - 2sin²a = 2cos²a - 1

    tan2a = \(\frac{2tan}{1 - tan²a}\)

    Chứng minh công thức nhân đôi

    sin2a = sin( a + a) = sina.cosa + cosa.sina = 2sina.cosa

    cos2a = cos( a + a) = cosa.cosa - sina.sina = cos²a - sin²a (1)

    Ta có: sin²a + cos²a = 1 (*)=> cos²a = 1 - sin²a, thay vào (1) => (1) = 1 - sin²a - sin²a = 1 - 2sin²a

    Từ (*) => sin²a = 1 - cos²a, thay vào (1)=> (1) = cos²a - ( 1 - cos²a ) = cos²a - 1 + cos²a = 2cos²a - 1

    tan2a = tan( a + a ) = \(\frac{tana + tana}{1 - tana.tana}\) = \(\frac{2tana}{1 - tan²a}\)

    Ví dụ 1

    Cho \(\sin\alpha = \frac{3}{5}\) với \(\frac{\pi}{2} \lt \alpha \lt \pi\). Tính \(\sin 2\alpha\), \(\cos 2\alpha\), \(\tan 2\alpha\).

    Xem lời giải

    Vì \(\frac{\pi}{2} \lt \alpha \lt \pi\) nên \(\cos\alpha \lt 0\), suy ra \(\cos\alpha = -\sqrt{1 - \frac{9}{25}} = -\frac{4}{5}\).

    \(\sin 2\alpha = 2\sin\alpha\cos\alpha = 2 \cdot \frac{3}{5} \cdot \left(-\frac{4}{5}\right) = -\frac{24}{25}\).

    \(\cos 2\alpha = 1 - 2\sin^2\alpha = 1 - \frac{18}{25} = \frac{7}{25}\).

    \(\tan 2\alpha = \frac{\sin 2\alpha}{\cos 2\alpha} = -\frac{24}{7}\).

    Ví dụ 2

    Cho \(\sin\alpha = \frac{1}{3}\). Tính \(\cos 2\alpha\).

    Xem lời giải

    \(\cos 2\alpha = 1 - 2\sin^2\alpha = 1 - 2 \cdot \frac{1}{9} = \frac{7}{9}\).
